# Cairn

面向 ADHD 与神经多样性人群的规划工具桌面/移动端原型。

**在线使用：** https://leddzh.github.io/cairn/

- 手机打开上面的网址后，可以「添加到主屏幕」，像 App 一样使用
- 电脑上用 Chrome / Edge 打开，也可以在地址栏右侧点「安装」
- 不需要注册、不需要联网、数据只存在你自己的设备上

课程作业项目 · 独立设计与实现

---

## 这是什么

把压垮人的大任务，拆成可以在两分钟内开始的一小步。

品牌名 Cairn 取自登山术语 —— 山径上的石堆路标。
它不催你登顶，只告诉你：方向没错，下一步在那儿。

## 技术说明

纯静态站点，没有任何服务端、没有任何外部依赖、不收集任何数据。
所有内容保存在使用者自己设备的浏览器本地存储里。

源码与完整交付物见本地项目目录（本仓库只放浏览器运行所需的 6 个文件）。
